Referencia de uso

Cada subcomando, flag y punto de integración. Para v0.3.0.

Instalación

Binario único en Go puro. Requiere Go 1.22+ para go install.

# última versión
$ go install github.com/julianshen/gogfy/cmd/gogfy@latest

# o fijar una versión
$ go install github.com/julianshen/gogfy/cmd/gogfy@v0.3.0

# compilar desde fuentes
$ git clone https://github.com/julianshen/gogfy && cd gogfy
$ go build -o gogfy ./cmd/gogfy

Inicio rápido

# construir el grafo del repo actual
$ gogfy run .
# → graphify-out/
#     graph.html        abre en cualquier navegador
#     graph.json        el grafo completo (la fuente de verdad)
#     GRAPH_REPORT.md   god nodes, puentes, conexiones sorprendentes, preguntas
#     wiki/             una página Markdown por comunidad

# conectar tu agente de IA (Claude Code, Cursor, Codex, etc.)
$ gogfy claude install

# reconstrucciones posteriores son incrementales
$ gogfy run . --update

El comando run

Pipeline principal: detect → extract → resolve → dedup → cluster → analyze → report → export.

$ gogfy run <root> [flags]
--out <dir>Directorio de salida (por defecto ./graphify-out/).
--updateIncremental: omite los archivos cuyo hash de contenido coincide con la caché.
--cluster-onlyOmite extracción; re-agrupa el graph.json existente bajo --out. Útil al ajustar la detección de comunidades.
--directedDibuja flechas en graph.html.
--no-vizOmite la visualización graph.html (más rápido, salida más pequeña).
--graphmlTambién emite graph.graphml (Gephi / yEd).
--cypherTambién emite graph.cypher (sintaxis MERGE para Neo4j).
--wikiTambién emite wiki/ — una página Markdown por comunidad.
--treeTambién emite tree.html — árbol de archivos colapsable en D3.
--follow-symlinksDesciende en directorios symlink dentro de la raíz (seguro ante ciclos vía registro de rutas resueltas).
--no-dedupOmite la deduplicación de entidades (más rápido; pueden quedar nodos duplicados).
--semantic --backend <name>Activa la extracción semántica con LLM. Ver Semántica.
--dry-runCon --semantic, imprime la estimación previa de tokens/coste y sale sin llamar al LLM.
--max-cost-usd <N>Aborta la ejecución si la estimación previa supera el tope semántico.
--transcribe-backend <name>Activa la transcripción de audio/vídeo (requiere --semantic).

Subcomandos — construir / explorar

gogfy watch <root>

Reconstrucción continua ante cambios de archivo (fsnotify). Registra el estado de arranque y la duración de cada reconstrucción.

$ gogfy watch . [--out dir] [--directed]

gogfy clone <git-url>

git clone en Go puro, seguido de la ejecución automática del pipeline. --no-run sólo clona.

$ gogfy clone https://github.com/foo/bar [--dir D] [--branch B] [--out dir] [--no-run]

gogfy validate <graph.json>

Verificación de esquema — verifica invariantes de nodos/aristas, ausencia de aristas colgantes y formato del language-ID.

gogfy report <graph.json>

Renderiza GRAPH_REPORT.md en stdout desde un grafo existente.

gogfy path <source> <target>

Ruta de conectividad más corta entre dos IDs de nodo.

$ gogfy path go:function:/api.go:Handler go:type:/db.go:DB [--graph graph.json]

gogfy diff <old.json> <new.json>

Diff estructural entre dos snapshots del grafo — nodos/aristas añadidos o eliminados, cambios de confianza.

gogfy manifest <root>

Snapshot mtime + SHA de todos los archivos fuente. --diff imprime la lista de archivos cambiados respecto al snapshot anterior. Lo usan los flujos incrementales.

$ gogfy manifest . [--out dir] [--diff] [--follow-symlinks]

gogfy merge-graphs <a.json> <b.json> ...

Unión de varios grafos en uno solo (grafos por repo → grafo a nivel de organización). Salida vía --out.

gogfy build-merge <prior.json> <next.json>

Merge incremental con poda de archivos eliminados — conserva nodos de archivos no tocados en prior, reemplaza nodos de los archivos de next, descarta nodos de archivos eliminados.

$ gogfy build-merge prior.json next.json [--files list.txt] [--out merged.json]

gogfy benchmark <graph.json>

Medición de reducción de tokens: cuántos consumiría un agente leyendo el corpus crudo frente al grafo.

$ gogfy benchmark graph.json [--corpus-words N] [--depth D] [--json]

Artefactos a partir de un grafo existente

gogfy wiki <graph.json>

Markdown navegable por agente, una página por comunidad, con referencias cruzadas. Índice en wiki/README.md.

gogfy site <graph.json>

Sitio HTML estático autocontenido con búsqueda, listo para GitHub Pages. Reutiliza un directorio wiki/ existente vía --wiki-dir.

gogfy tree <graph.json>

Vista HTML de árbol de archivos colapsable en D3.

gogfy callflow <graph.json>

Diagrama de arquitectura en Mermaid con etiquetas y una sección de Key Insights.

$ gogfy callflow graph.json [--max-sections N] [--max-nodes M] [--max-edges E] [--project NAME]

gogfy obsidian <graph.json>

Vault de Obsidian: un Markdown por nodo, [[wikilinks]] para aristas, resúmenes de comunidad.

gogfy svg <graph.json>

SVG estático force-directed (sin JS) — para empotrar en docs, posts, donde sea.

$ gogfy svg graph.json [--out path.svg] [--labels] [--width N] [--height N] [--iterations N]

gogfy labels <graph.json>

Genera o edita etiquetas legibles para cada comunidad. --force sobrescribe.

gogfy neo4j-push <graph.json>

Push directo de graph.json a un Neo4j en ejecución vía protocolo Bolt — alternativa a escribir graph.cypher.

$ gogfy neo4j-push graph.json --uri neo4j://localhost:7687 --user U --password P [--database D]

Integración con CI

Hace fallar la build de un PR cuando el grafo retrocede más allá de los umbrales. Resumen Markdown en stdout (canalizable a gh pr comment); código de salida distinto de cero al sobrepasar.

$ gogfy ci base.json head.json \
    --max-removed-nodes 0 \
    --max-removed-edges 10 \
    --max-new-ambiguous 5
--max-removed-nodes <N>Falla si desaparecen más de N nodos.
--max-removed-edges <N>Falla si desaparecen más de N aristas.
--max-new-ambiguous <N>Falla si aparecen más de N aristas AMBIGUOUS nuevas.

Grafo global (multi-repo)

Un almacén compartido de grafos por repo en tu directorio home, consultable de forma transversal.

$ gogfy global add graphify-out/graph.json --as myrepo
$ gogfy global list
$ gogfy global path <source> <target>        # conectividad entre repos
$ gogfy global remove myrepo
$ gogfy global path                            # muestra la ruta del almacén

Plataformas de agentes

19 plataformas soportadas. La instalación combo configura el servidor MCP + un fragmento en la documentación + un hook post-commit de una vez:

$ gogfy <platform> install
$ gogfy <platform> uninstall            # añade --purge para eliminar también fragmento y hook

# o paso a paso
$ gogfy install --platform <platform>         # sólo el archivo MCP
$ gogfy install-instructions --file CLAUDE.md # sólo el fragmento de docs
$ gogfy hook install                          # hooks post-commit + post-checkout

Plataformas disponibles: claude · codex · cursor · vscode · gemini · opencode · kilocode · qwen · kimi · aider · claw · copilot · droid · trae · trae-cn · hermes · kiro · pi · antigravity

Hooks de Git

Hooks post-commit + post-checkout que reconstruyen el grafo automáticamente, más un merge driver opcional que une graph.json automáticamente durante los merges.

$ gogfy hook install [--repo dir] [--gogfy-bin path] [--out dir]
$ gogfy hook uninstall [--repo dir]
$ gogfy hook status [--repo dir]
$ gogfy hook install-merge-driver [--repo dir] [--gogfy-bin path]
$ gogfy hook uninstall-merge-driver [--repo dir]

Servidor MCP

Servidor MCP stateless basado en stdio. La instalación combo lo configura por ti; gogfy serve lo ejecuta directamente para pruebas o integraciones no estándar.

$ gogfy serve [--graph graphify-out/graph.json] [--report graphify-out/GRAPH_REPORT.md]

Herramientas MCP expuestas

Diez herramientas que tu agente puede invocar. Todas de sólo lectura; ninguna modifica el grafo.

gogfy_god_nodesLas N entidades con más conexiones (los nodos hub estructurales).
gogfy_explainResumen por nodo: qué es, quién lo llama/usa, de qué depende.
gogfy_queryListado filtrado — por kind, archivo, comunidad, subcadena de label.
gogfy_pathRuta de conectividad más corta entre dos nodos.
gogfy_get_neighborsVecinos directos de un nodo, desglosados por relación.
gogfy_graph_statsConteos: nodos/aristas por kind/relation; tamaños de comunidad.
gogfy_get_communityMiembros y resumen de una comunidad.
gogfy_traverseBFS/DFS desde un nodo, con filtros de profundidad y relación.
gogfy_impactAlcanzabilidad inversa: los dependientes transitivos que se rompen si cambias un nodo.
gogfy_repomapMapa de los símbolos más importantes, agrupados por archivo y ordenados por PageRank (opcionalmente enfocado en tu tarea).

Extracción semántica (opcional, vía LLM)

Activar --semantic enriquece el grafo con entidades y hyperaristas N-arias extraídas de documentos e imágenes. Clientes HTTP en Go puro para cada backend — sin dependencias de SDK.

$ gogfy run . --semantic --backend anthropic --dry-run    # estimación previa
$ gogfy run . --semantic --backend anthropic --max-cost-usd 5.00
anthropicANTHROPIC_API_KEY · Claude (Sonnet por defecto)
openaiOPENAI_API_KEY
geminiGEMINI_API_KEY
kimiMOONSHOT_API_KEY · Moonshot / Kimi
bedrockAWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION · Claude vía AWS Bedrock (SigV4 en Go puro)
ollamaEndpoint local de Ollama (sin key)

Los resultados se cachean en <out>/.gographify-cache/semantic/; al rerun con --update sólo se vuelven a pedir al LLM las entradas cambiadas.

Ingesta de URL

Trae una URL al corpus como fuente del grafo: fetch seguro contra SSRF, extracción HTML al estilo readability, metadatos OpenGraph, reescritura de URLs de GitHub, ruteo de PDFs de arXiv, oembed de YouTube.

$ gogfy ingest https://example.com/post [--out dir]
$ gogfy ingest https://youtu.be/<id> --audio        # extracción de audio en Go puro para --transcribe
$ gogfy add ...                                     # alias de ingest

Gestión de caché

El flujo incremental --update y los resultados semánticos viven bajo <out>/.gographify-cache/.

$ gogfy cache stats [--out dir]                                        # tamaño y conteos
$ gogfy cache clear [--out dir] [--older-than 7d | --all]              # GC

Archivos de configuración y convenciones

.graphifyignorePatrones glob a omitir a nivel de walk (estilo gitignore).
.graphifyincludeLista de permitidos para archivos/paths ocultos que normalmente se saltarían.
tsconfig.json (paths)Alias de path JS/TS (@app/* → src/*) se leen y resuelven antes del merge downstream.
<out>/.gographify-cache/Caché por hash de contenido (extracción) + caché de resultados semánticos. Se puede borrar; se reconstruye.
<out>/graph.jsonLa fuente de verdad (esquema versionado con campo schema_version).
<out>/GRAPH_REPORT.mdSellado con el SHA corto de HEAD del corpus, para que un artefacto desactualizado sea visiblemente viejo.

Garantía de determinismo

graph.json es idéntico byte a byte entre ejecuciones repetidas sobre el mismo corpus. Esto es esencial para --update / diff / ci — diffs espurios romperían la barrera de CI.

Dos piezas lo aseguran: el LouvainClusterer determinista propio de gogfy como default (iteración ordenada de nodos, desempates ordenados), y schema.SortEdges aplicado a la salida de aristas del dedup. Vigilado por un test de regresión end-to-end que ejecuta el pipeline dos veces sobre un fixture y falla ante cualquier diferencia de bytes.
