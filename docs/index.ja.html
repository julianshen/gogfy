AIエージェントが
ナビゲートできるコード知識グラフ。

Pure-Go の静的解析ツール。コード本体に加えて、ドキュメント・PDF・Webページ・YouTube まで、 関数呼び出し、型階層、パッケージ依存、ドキュメント参照、意味的概念 —— すべての信号を一つの型付きグラフに統合します。あなたのコーディングエージェントが、 リポジトリについて答える「前」に読む知識構造です。

GitHubで見る リリース 使い方
$ go install github.com/julianshen/gogfy/cmd/gogfy@latest
何ができるか

一つのグラフに、エージェントが必要なすべての信号を。

多くのエージェントは grep でリポジトリを彷徨います。gogfy は構造を一度だけ抽出し —— 呼び出し、型階層、パッケージ依存、ドキュメント参照 —— それを内蔵の MCP サーバーから提供します。 エージェントはファイルをスキャンする代わりに、「これを呼んでいるのは誰?」とグラフに問い合わせます。

28+ 言語

Go、Python、TS/JS、Java、C/C++、C#、Rust、Kotlin、Scala、Swift、Ruby、PHP、Dart、Lua、Haskell、OCaml、Elixir、Erlang、R、Julia、Zig、Fortran、Bash、Svelte など —— すべて pure-Go tree-sitter 経由。Python も LLM も不要。

ドキュメントも対象

Markdown、HTML、PDF、DOCX、PPTX、XLSX、RST、TOML、YAML —— コメントではなく一級のグラフ情報源として扱います。形式を跨いだグラフがシームレスに合成されます。

型付きエッジ

calls、contains、imports(コーパス内モジュールに解決)、inherits、implements、embeds、references、加えて意味抽出による N項ハイパーエッジ。

仕組み

8段階のパイプライン、どこでも止められます。

各段階は pure-Go・決定論的・独立にテスト可能。 tree-sitter 以外に cgo なし、Python なし、--semantic でオプトインしない限り LLM 呼び出しもありません。

クイックスタート

3つのコマンドで、エージェントがグラフを読み始めます。

# 1. インストール
$ go install github.com/julianshen/gogfy/cmd/gogfy@latest

# 2. 現在のリポジトリでグラフを生成
$ gogfy run .
#   graphify-out/
#   ├── graph.html       ブラウザで開ける
#   ├── GRAPH_REPORT.md  god ノード、意外な接続、推奨される質問
#   └── graph.json       完全なグラフ

# 3. AI エージェントに接続(19 プラットフォーム対応)
$ gogfy claude install
#   MCP サーバーを設定し、CLAUDE.md にスニペットを追加し、
#   自動再ビルドの post-commit フックを仕込みます。
#   他のターゲット:cursor、codex、vscode、gemini、aider、…

これで、エージェントはファイルを grep する代わりにグラフを照会して答えます —— gogfy_god_nodes、gogfy_traverse、gogfy_path、gogfy_get_neighbors、gogfy_explain。

機能

現実のコードベースのために。

型階層

パッケージを跨いで inherits / implements / embeds を解決。Python、Java、TS、C#、Kotlin、Scala、Swift、Dart、Ruby、PHP、Rust、Go(struct embedding)対応。

パッケージ間依存

ローカルな import を実際のモジュールに解決し、本物のファイル間依存エッジを生成します。外部 import は「観測された import」事実として保持。

デフォルトで決定論的

同じコーパスを2回走らせると、graph.json はバイト単位で一致します。e2e 回帰テストで保証。--update / graphdiff / スナップショットの安定性が依存します。

MCP サーバー内蔵

gogfy serve がグラフを MCP ツールとして公開。19 のエージェントプラットフォーム —— Claude Code、Cursor、Codex、Gemini CLI、Copilot CLI、Aider など —— が独自配線なしで読み取れます。

任意の意味抽出

--semantic でオプトイン:文書や画像からエンティティと N項ハイパーエッジを抽出。バックエンド:Anthropic、OpenAI、Gemini、Bedrock、Kimi、Ollama。事前のコスト見積、--dry-run、予算上限あり。

増分実行 & キャッシュ

--update は内容ハッシュキャッシュで変更ファイルのみ再構築。意味抽出結果は .gographify-cache/ にキャッシュ。--watch で継続再ビルド。

多彩な出力形式

JSON(バージョン付きスキーマ)、インタラクティブ HTML、Markdown レポート、Gephi/yEd 向け GraphML、Neo4j 向け Cypher(または Bolt 直接送信)、SVG、デプロイ可能な静的ドキュメントサイト(gogfy site)。

ファイルシステムを超えて

SSRF 安全な fetch を使う URL 取り込み、readability 風の HTML 抽出、OpenGraph メタデータ、GitHub URL の書き換え、arXiv PDF ルーティング、YouTube oembed + 純 Go の音声抽出(transcribe 用)。

堅牢化を内蔵

機密ファイルパターンを walk 層で検知、Label/SourceFile を AddNode の入口で集中サニタイズ、SSRF ガード、PDF/OOXML のパニック耐性。失敗は黙らず診断情報付きで縮退します。
