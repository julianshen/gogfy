Grafos de conocimiento
que tu agente de IA puede navegar.

Un analizador estático nativo en Go que convierte cualquier base de código —junto con sus documentos, PDFs, páginas web y vídeos de YouTube— en un grafo de conocimiento tipado. Llamadas, tipos, herencia, imports, dependencias, conceptos semánticos: todas las señales en una sola estructura navegable que tu agente lee antes de responder preguntas sobre tu repo.

Qué hace

Un grafo. Todas las señales que tu agente necesita.

La mayoría de agentes se las arreglan con grep sobre el repo. gogfy extrae la estructura una vez —llamadas, jerarquías de tipos, dependencias entre paquetes, referencias en docs— y la sirve a través de un servidor MCP integrado. Tu agente le pregunta al grafo "¿quién llama a esto?" en lugar de escanear archivos.

28+ lenguajes

Go, Python, TS/JS, Java, C/C++, C#, Rust, Kotlin, Scala, Swift, Ruby, PHP, Dart, Lua, Haskell, OCaml, Elixir, Erlang, R, Julia, Zig, Fortran, Bash, Svelte y más — todo vía tree-sitter en Go puro, sin Python ni LLM requeridos.

Los documentos también

Markdown, HTML, PDF, DOCX, PPTX, XLSX, RST, TOML, YAML — tratados como fuentes de primer nivel del grafo, no como comentarios. Los grafos multi-formato se componen sin fricción.

Aristas tipadas

calls, contains, imports (resuelto a módulos del corpus), inherits, implements, embeds, references, más hyperaristas N-arias provenientes de la extracción semántica.

Cómo funciona

Un pipeline de ocho etapas en el que puedes detenerte en cualquier punto.

Cada etapa es Go puro, determinista y testeable de forma independiente. Sin cgo (fuera de tree-sitter), sin Python, sin LLM a menos que actives --semantic.

1Detect
recorrer, clasificar, omitir secretos
2Extract
AST tree-sitter → nodos
3Resolve
calls, methods, herencia, imports
4Dedup
exacto + difuso + arbitraje LLM
5Cluster
Louvain determinista
6Analyze
god nodes, conexiones sorprendentes, puentes
7Report
GRAPH_REPORT.md
8Export
JSON / HTML / GraphML / Cypher / SVG
Inicio rápido

Tres comandos, y tu agente lee el grafo.

# 1. instalar
$ go install github.com/julianshen/gogfy/cmd/gogfy@latest

# 2. construir el grafo para el repo actual
$ gogfy run .
#   graphify-out/
#   ├── graph.html        abre en cualquier navegador
#   ├── GRAPH_REPORT.md   god nodes, conexiones sorprendentes, preguntas sugeridas
#   └── graph.json        el grafo completo

# 3. conectar tu agente de IA (19 plataformas soportadas)
$ gogfy claude install
#   instala el servidor MCP, agrega un fragmento a CLAUDE.md,
#   configura un hook post-commit que reconstruye automáticamente.
#   Otros destinos: cursor, codex, vscode, gemini, aider, ...

Ahora tu agente responde preguntas sobre el repo consultando el grafo — gogfy_god_nodes, gogfy_traverse, gogfy_path, gogfy_get_neighbors, gogfy_explain — en lugar de hacer grep.

Características

Pensado para bases de código reales.

Jerarquía de tipos

inherits / implements / embeds resueltos entre paquetes para Python, Java, TS, C#, Kotlin, Scala, Swift, Dart, Ruby, PHP, Rust, Go (struct embedding).

Dependencias entre paquetes

Los imports locales se resuelven a los módulos que realmente nombran — aristas reales de dependencia en lugar de stubs sin destino. Los imports externos permanecen como hechos observados.

Determinista por defecto

graph.json es idéntico byte a byte entre ejecuciones sobre el mismo corpus. Protegido por un test de regresión e2e. Necesario para --update / graphdiff y la estabilidad de snapshots.

Servidor MCP integrado

gogfy serve expone el grafo como herramientas MCP. 19 plataformas de agentes soportadas — Claude Code, Cursor, Codex, Gemini CLI, Copilot CLI, Aider y más — pueden leerlo sin pegamento a medida.

Enriquecimiento semántico opcional

Activa --semantic: entidades e hyperaristas N-arias extraídas de tus docs e imágenes. Backends: Anthropic, OpenAI, Gemini, Bedrock, Kimi, Ollama. Estimación de coste previa + --dry-run + tope de presupuesto.

Incremental y cacheado

--update reconstruye sólo los archivos modificados vía caché de hash de contenido. Los resultados semánticos se cachean en .gographify-cache/. --watch para reconstrucción continua.

Múltiples formatos de exportación

JSON (esquema versionado), HTML interactivo, reporte Markdown, GraphML para Gephi/yEd, Cypher para Neo4j (o push directo por Bolt), SVG, sitio estático desplegable (gogfy site).

Más allá del sistema de archivos

Ingesta de URL con fetch seguro contra SSRF, extracción HTML al estilo readability, metadatos OpenGraph, reescritura de URLs de GitHub, ruteo de PDFs de arXiv, oembed de YouTube + extracción de audio en Go puro para transcripción.

Endurecimiento integrado

Patrones de archivos sensibles a nivel de walk, saneamiento central de Label/SourceFile en AddNode, guardas SSRF, lectores tolerantes a panic en PDF/OOXML. Los fallos degradan con diagnósticos, no en silencio.

Rendimiento

~4× más rápido de punta a punta en v0.3.0.

Medido sobre un corpus real de 220 archivos Go (3.885 nodos, 14.869 aristas). El profiling reveló que los costes no estaban donde la intuición decía — las mejoras vinieron de un Brandes paralelo con índices enteros y de levantar invariantes fuera del bucle O(n²) del dedup difuso.
